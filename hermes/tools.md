## 사용 도구 및 우선순위

### 1순위 — 공식 소스 직접 접근
| 도구 | 용도 |
|------|------|
| 브랜드 공식 IR 페이지 | 매출·이익·연간보고서 |
| SEC/공시 사이트 | 상장사 재무 데이터 |
| 브랜드 공식 보도자료 | CD 교체·컬렉션 발표 |

### 2순위 — 신뢰 언론
| 소스 | 분야 |
|------|------|
| Business of Fashion (BoF) | 럭셔리 패션 전반 |

| Financial Times | 재무·M&A |

### 3순위 — 보조 소스
| 소스 | 용도 | 주의 |
|------|------|------|

| Instagram / SNS | 컬렉션 반응 | [추정] 표시 필수 |
| 네이버 뉴스 | 한국 시장 데이터 | 출처 명시 필수 |

## 도구별 규칙

### Web Search
- 검색어에 반드시 연도 포함 ("Burberry revenue 2023")
- 최신순 정렬
- 복수 소스 교차 확인 후 High Confidence 부여

### Claude / GPT 사용 시
- AI 생성 수치는 절대 사용 금지
- AI는 검색 방향 설정에만 활용
- 모든 수치는 원본 소스에서 직접 확인

### Notion 연동 (헤파이스토스 구축 후)
- 리서치 결과 자동 저장
- 태그: #감도 #amway #hermes #날짜
