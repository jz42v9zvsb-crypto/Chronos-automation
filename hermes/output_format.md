# Hermes — Output Format

## 기본 출력 구조

```
## HERMES REPORT
날짜: YYYY-MM-DD
주제: [리서치 주제]
의뢰: [감도 / Amway / 기타]
---

### ⚡ KEY FACTS (3줄 요약)
1. [가장 중요한 사실 — 수치 포함]
2. [두 번째 사실]
3. [세 번째 사실]

---

### 📊 DATA
[수치·통계·데이터 정리]
- 항목: 수치 (출처, 연도) [Confidence: High/Medium/Low]

---

### 📰 TIMELINE
[날짜순 사건 정리]
- YYYY.MM: 사건 (출처)

---

### 🔗 SOURCES
1. 출처명 — URL or 문서명
2. 출처명 — URL or 문서명

---

### ⚠️ UNVERIFIED
[확인 못 한 정보, 루머, 추정값 별도 분리]
- [추정] 내용 (근거)
```

---

## 감도 채널 전용 포맷

```
## HERMES × 감도
브랜드: [브랜드명]
각도: [영상 주제 키워드]
---

### BRAND SNAPSHOT
- 설립: 연도, 창립자
- 현 CD: 이름 (취임 연도)
- 2023 매출: £XX (전년비 +/-XX%) [출처]
- 포지셔닝: [한 줄]

### CD HISTORY
| 연도 | CD | 재임기간 | 대표 레거시 |
|------|-----|---------|------------|

### KEY CONTROVERSY / TURNING POINT
- 날짜: 사건 (출처)

### NUMBERS TO USE IN SCRIPT
PPT·스크립트에 바로 쓸 수 있는 수치만 추출
- "XXXX년 매출 XX% 하락" (출처)
- "XX개국 XXX개 매장" (출처)
```

---

## Amway 전용 포맷

```
## HERMES × Amway
주제: [리서치 주제]
페르소나: [영맘 / 세컨 밀레니얼 / 밀레니얼 / 은준세 / 전체]
---

### MARKET DATA
- 관련 통계 (출처, 연도)

### BENCHMARK
- 타사/타업계 유사 사례 (출처)

### NUMBERS TO USE IN DECK
슬라이드에 바로 쓸 수 있는 수치
```
