```
## HERMES × 감도
브랜드: Burberry
각도: Daniel Lee 취임 후 무엇이 달라졌나
날짜: 2024-01-15
---

### BRAND SNAPSHOT
- 설립: 1856년, Thomas Burberry
- 현 CD: Daniel Lee (2022년 10월 취임)
- 2023 매출: £2.97B (전년비 +10%) [Burberry Annual Report 2023]
- 영업이익: £634M (전년비 +7%) [Burberry Annual Report 2023]
- 포지셔닝: British luxury, 트렌치코트·체크 패턴 헤리티지

### CD HISTORY
| 연도 | CD | 재임기간 | 대표 레거시 |
|------|-----|---------|------------|
| 2001-2004 | Roberto Menichetti | 3년 | 헤리티지 현대화 시도 |
| 2004-2018 | Christopher Bailey | 14년 | 디지털 퍼스트, 브랜드 글로벌화 |
| 2018-2022 | Riccardo Tisci | 4년 | 스트리트 럭셔리, TB 모노그램 |
| 2022- | Daniel Lee | 현재 | 영국성 재정의, 기사단 로고 부활 |

### KEY FACTS
- Daniel Lee 취임 첫 컬렉션: 2023 SS (2022년 9월 런던패션위크)
- 기사단 문장(Equestrian Knight) 로고 복원 — TB 모노그램 축소
- 2023 FW: "British weather" 테마, 실용성과 럭셔리 결합
- 한국 면세 매출 회복세: 2023 H1 아시아태평양 +16% [Burberry AR 2023]

### NUMBERS TO USE IN SCRIPT
- "2022년 10월, 버버리는 보테가 베네타를 부활시킨 Daniel Lee를 영입했다"
- "취임 후 첫 컬렉션에서 14년간 사용한 TB 모노그램을 버리고 1901년 기사단 로고를 꺼냈다"
- "2023년 매출 £2.97B, 전년 대비 10% 성장" (Burberry Annual Report 2023)

### UNVERIFIED
- [추정] Daniel Lee 연봉 패키지 £5M+ (단일 소스, 미확인)
- [추정] 2024 매출 목표 £4B (애널리스트 추정, 공식 미발표)

### SOURCES
1. Burberry Group plc Annual Report 2022/23 — burberry.com/investors
2. BoF, "Daniel Lee's First Burberry Collection" — businessoffashion.com
3. Vogue Business, "Burberry's new logo explained" — voguebusiness.com
```

## 나쁜 출력 예시 (하지 말 것)

```
❌ 버버리는 최근 실적이 좋지 않아서 CD를 교체한 것 같습니다.
   Daniel Lee는 매우 창의적인 디자이너로 앞으로 버버리를 잘 이끌 것으로 보입니다.
   
→ 문제점:
   - "같습니다" = 추측
   - "잘 이끌 것" = 의견·예측
   - 수치 없음
   - 출처 없음
   - PPT에 쓸 수 없는 문장
```
