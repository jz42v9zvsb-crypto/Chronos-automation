# Athena — Examples

## 좋은 출력 예시 (Amway STP)

```
## ATHENA — Strategic Interpretation
프로젝트: amway-stp
입력: knowledge/amway-stp/ (Hermes 리서치 1건)
---

### 🎯 STRATEGIC ANGLE
은준세는 "노후가 불안한 세대"가 아니라 "아직 쓸 돈과 의지가 있는 세대"로
재정의해야 한다. (근거: 월 평균 소득 290만원 통계청 2023 — 제공된 지식)

### 👥 AUDIENCE INSIGHT
- 건강·여행·재테크 관심이 높음 → '생존'이 아닌 '삶의 질' 프레임이 통한다
  (근거: 라이프스타일 관심사 조사, 제공된 지식)
- 국민연금 평균 67만원이라는 불안 요인은 '대안 소득' 메시지의 진입점

### 🪜 MESSAGE HIERARCHY
1. "은퇴 이후에도 주도권을 쥔다" — 자기결정 프레임 (핵심)
2. 건강/관계/소득의 구체적 솔루션 연결 (보조)
3. 동년배 레퍼런스·커뮤니티 (보조)
- 버릴 것: '노후 빈곤 공포 마케팅' — 자기효능감을 깎아 역효과

### 🔎 IMPLICATIONS
- 가처분소득이 있는 집단이므로 가격 저항보다 '명분'이 구매를 가른다
- STP의 Targeting은 연령이 아니라 '태도(주도적 vs 수동적)'로 잘게 나누는 편이 강하다

### ⚠️ RISKS / WEAK CLAIMS
- '라이프스타일 관심 60%'는 단일 조사 — 일반화에 주의 [Confidence: Medium]
- 지역/소득 분포 데이터 없음 → Hermes 추가 리서치 필요

### 🧭 RECOMMENDED NARRATIVE DIRECTION
"불안"이 아니라 "주도권"에서 출발 → 구체적 소득/건강 솔루션 → 동년배 증거 →
행동 제안. 공포 대신 자기효능감을 일관되게 유지한다.
```

## 나쁜 출력 예시 (하지 말 것)

```
❌ 은준세 시장은 5조원 규모로 매년 12% 성장하고 있습니다.
   따라서 지금 진입하면 선점 효과가 큽니다.

→ 문제점:
   - "5조원 / 12%" = 제공된 지식에 없는 수치를 지어냄 (원칙 1·2 위반)
   - 출처 없음 — 이것은 Hermes의 영역이며 근거 없이 단정하면 안 됨
   - 해석이 아니라 가짜 사실 생성
```
