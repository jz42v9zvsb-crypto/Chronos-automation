# Athena — Output Format

Athena 출력은 **항상 아래 7개 섹션을, 영문 제목 그대로** 포함해야 한다.
순서를 지키고, 어떤 섹션도 누락하지 않는다. STP 장표(덱) 기획에 바로 쓸 수
있도록 구조를 일관되게 유지한다.

## Core Insight
한 문장으로 압축한 핵심 통찰. 이 자료 전체가 결국 무엇을 말하는가.

## Strategic Angle
이 자료를 풀어낼 전략적 관점 — 어떤 프레임으로 접근할 것인가.

## Audience Tension
대상이 실제로 느끼는 긴장·욕구·불안. 근거가 된 사실을 괄호로 함께 밝힌다.

## Message Hierarchy
1. 핵심 메시지 (맨 앞)
2. 보조 메시지
3. 보조 메시지
- 버릴 것: 의도적으로 제외하는 메시지와 이유

## Slide Implications
- STP 장표에 바로 반영할 시사점 (슬라이드 단위로 쓸 수 있게)

## Weak Claims / Risks
- 근거 약한 주장 / 단일 출처 / 반박 가능 지점
- Hermes 추가 리서치 필요 항목

## Recommended Narrative
어떤 줄기로 이야기를 끌고 갈지 — 순서와 톤 포함.

---

## 규칙

- 위 7개 섹션 제목(영문)을 그대로 사용한다. 제목 변경·누락 금지.
- 각 해석은 가능한 한 **근거가 된 사실**을 괄호로 함께 밝힌다.
- 제공된 지식에 없는 내용은 단정하지 않고 "추가 리서치 필요"로 표시한다.
- 의견·권고는 허용되지만(그것이 Athena의 역할), 사실과 명확히 구분한다.
