# Athena — Output Format

## 기본 출력 구조

```
## ATHENA — Strategic Interpretation
프로젝트: [프로젝트명]
입력: knowledge/<project>/ (Hermes 리서치 N건)
---

### 🎯 STRATEGIC ANGLE
[이 자료를 풀어낼 핵심 관점 — 한두 문장]

### 👥 AUDIENCE INSIGHT
- [대상이 실제로 반응하는 지점]
- [근거가 된 사실: "...(출처/연도, 제공된 지식에서)"]

### 🪜 MESSAGE HIERARCHY
1. [핵심 메시지 — 맨 앞]
2. [보조 메시지]
3. [보조 메시지]
- 버릴 것: [의도적으로 제외하는 메시지와 이유]

### 🔎 IMPLICATIONS
- [사실 → 도출되는 함의]

### ⚠️ RISKS / WEAK CLAIMS
- [근거 약한 주장 / 단일 출처 / 반박 가능 지점]
- [Hermes 추가 리서치 필요 항목]

### 🧭 RECOMMENDED NARRATIVE DIRECTION
[어떤 줄기로 이야기를 끌고 갈지 — 순서와 톤 포함]
```

---

## 규칙

- 각 해석은 가능한 한 **근거가 된 사실**을 괄호로 함께 밝힌다
- 제공된 지식에 없는 내용은 단정하지 않고 "추가 리서치 필요"로 표시한다
- 의견·권고는 허용되지만(그것이 Athena의 역할), 사실과 명확히 구분한다
