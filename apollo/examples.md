# Apollo — Examples

## 좋은 출력 예시 (요약, Amway STP)

```
## Deck Title
- "은퇴가 아니라, 주도권"
- "은준세, 아직 쓸 힘이 있다"

## Headline Options
- "노후의 불안 대신, 삶의 주도권"
- "끝이 아니라, 다음 장의 시작"

## Slide Narrative
- Slide 1 — 은준세, 아직 주도권이 있다
  - Body: 월 290만원 소득의 세대. 노후는 끝이 아니라 다음 장의 시작이다.
  - Visual hint: 소득·활동 인포그래픽
- Slide 2 — 불안의 자리에 솔루션을
  - Body: 국민연금 67만원의 공백은 공포가 아니라 '대안 소득'의 출발점이다.

## Section Flow
- 1) 재정의 → 2) 솔루션 → 3) 동년배 증거 → 4) 행동 제안

## Tone Notes
- 자기효능감 중심. 공포 마케팅 배제(전략 지침 준수).

## Flags / Open Questions
- [근거 필요] 290만원 수치의 최신 출처 재확인
- 전략 변경 없음
```

---

## 나쁜 출력 (하지 말 것)

```
❌ 전략에 없는 "시장 5조원, 연 12% 성장" 같은 수치를 지어내 카피에 삽입
❌ Athena가 정한 '공포 마케팅 배제' 방향을 말없이 뒤집어 공포 카피로 작성 (flag 없음)
❌ 초안 단계에서 PPTX 파일을 만들려 시도
```
